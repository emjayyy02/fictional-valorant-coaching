# OFFANGLE

A responsive landing page for a fictional VALORANT coaching brand, focused on competitive visual design and clear service presentation.

## About

OFFANGLE is a fictional client concept created as a small frontend portfolio exercise. The brand, coach Kai “Koda” Ren, rank, and coaching background are invented. No real client, coaching service, booking, or payment flow is represented.

## Built With

- HTML
- CSS
- Vanilla JavaScript

## Highlights

- Ink-purple and lavender palette with a restrained lime accent, oversized condensed headings, and tactical details.
- Original SVG map artwork and a CSS round-review illustration; no official game artwork or external image dependencies.
- Hero, three coaching focus areas, training method, fictional coach profile, and closing brand statement.
- Responsive layouts for desktop, tablet, and mobile, including a compact mobile menu.
- Semantic landmarks, keyboard focus styles, skip link, reduced-motion support, and navigation that works without JavaScript.

## Running Locally

Open `index.html` directly in a modern browser. No installation or build step is needed. Alternatively, serve this folder with any static local server.

## Project Structure

```text
index.html
styles.css
script.js
assets/
  favicon.svg
  tactical-map.svg
README.md
```

System fonts keep the page self-contained: Impact / Arial Narrow for display headings, Arial / Helvetica for body text, and Courier New for labels. Exact font appearance depends on the device.

## Checks

Reviewed in the Codex browser at 1440, 1024, 768, and 390px, with an additional overflow check at 320px. Checked menu selection, Escape and focus behavior, section links, image loading, JavaScript syntax, and browser console output. Main text color pairs exceed 4.5:1 contrast. Reduced motion is handled in CSS; no animation library is used.
